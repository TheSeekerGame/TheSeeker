# Game Design

This section records the high-level design vision for The Seeker: who it is for, how it should look and feel, what it means, how it works as an open-source brand, and which mechanics it aims for.

These pages describe intent, not the current build. Some details have changed in the game itself. For example, devices, weapons, and passives come from research and crafting at capsules, abilities are copied from creatures, and the creature roster differs from the ecosystem sketch. The [Architecture](../architecture/README.md) pages and the source code describe how the game currently works.
